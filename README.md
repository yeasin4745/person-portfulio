# Yeasin — Full-Stack Developer Portfolio

A personal full-stack developer portfolio showcasing frontend, backend, AI/ML, tooling, projects, and technical writing.

- **Live portfolio:** [yeasin-4745.vercel.app](https://yeasin-4745.vercel.app/)
- **Other portfolio:** [yeasin4745.vercel.app](https://yeasin4745.vercel.app/)

## Tech Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, and wouter.

## Getting Started

This project uses [pnpm](https://pnpm.io/).

```bash
pnpm install
pnpm dev
```

Create a production build and preview it locally with:

```bash
pnpm build
pnpm preview
```

## Project Structure

| Directory | Purpose                                                                    |
| --------- | -------------------------------------------------------------------------- |
| `client/` | Frontend application source, pages, components, styles, and public assets. |
| `shared/` | Shared portfolio constants and data used by the frontend.                  |

This repository is a **static frontend-only site**. It does not contain a backend or server; the application is built and deployed as a Vite frontend on Vercel.
